Flask Wrapping Concepts (Decorators) Prototype

This prototype demonstrates how function wrappers (decorators) control access across 3 distinct route levels.

Route Type Decorator Used Access Rule Test Link
Type 1: Public None (Standard view) Anyone can view (guests & users) Visit Home
Type 2: Protected @login_required Must be logged in (any user role) Visit Dashboard
Type 3: Role-Restricted @role_required('admin') Must be logged in AND role must be admin Visit Admin Panel

How to test the behavior:

  1. Try clicking Dashboard or Admin Only while logged out → redirects to Login with warning.
  2. Log in as alice (role: user) → Dashboard works, but clicking Admin triggers an Unauthorized warning.
  3. Log out and log in as admin (role: admin) → Both Dashboard and Admin Panel work.
