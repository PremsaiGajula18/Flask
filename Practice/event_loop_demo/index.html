JavaScript Event Loop In Action

Watch the exact execution order between Synchronous code, Promises (Microtasks), and Timers (Macrotasks).

The Code We Are Running:

console.log("1. Synchronous START");

setTimeout(() => {
  console.log("4. Timer (setTimeout 0ms)");
}, 0);

Promise.resolve().then(() => {
  console.log("3. Promise .then()");
});

console.log("2. Synchronous END");

Why did it print in this order?

Step 1: Call Stack (Synchronous)

Lines 1 and 4 run immediately on the Call Stack. Nothing can interrupt them.

Step 2: Microtask Queue (Promise)

Promises are placed in the high-priority Microtask Queue. The Event Loop empties ALL Microtasks as soon as the Call Stack is empty.

Step 3: Macrotask / Task Queue (Timer)

Even with 0ms delay, setTimeout goes to the Macrotask Queue. It must wait until all synchronous code AND all Microtasks have finished.
