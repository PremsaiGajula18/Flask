01. Fundamentals of Flask & Architecture

Flask is a lightweight, extensible micro-framework written in Python. It is founded on two core architectural pillars: the Werkzeug WSGI toolkit (which handles HTTP routing, request/response objects, and server bridging) and the Jinja2 template engine (which renders dynamic HTML).

Real-World Analogy: Think of Flask as a modular skeleton house. Unlike Django (which comes fully furnished with admin, ORM, and auth pre-installed), Flask gives you the strong structural framing, allowing you to choose exactly which plumbing, interior walls, and fixtures (SQLAlchemy, Jinja, bcrypt) to plug in.

Standard Minimal Flask Program

from flask import Flask

# 1. Create the application instance
app = Flask(__name__)

# 2. Define route with view function
@app.route('/')
def home():
    return "Hello, Flask Exam!"

# 3. Development server entry point
if __name__ == '__main__':
    app.run(debug=True, port=5000)

Line-by-Line Written Examination Breakdown:

  • from flask import Flask: Imports the WSGI-compliant Flask class from the flask package.
  • app = Flask(__name__): Instantiates the application. __name__ is a special Python built-in variable resolving to '__main__' when executed directly. Flask uses it to determine root path for locating templates/ and static/ directories.
  • @app.route('/'): A Python decorator mapping the web request path / to the home() handler function.
  • def home(): return ...: The view function returning an HTTP response body (string, HTML, or tuple).
  • if __name__ == '__main__':: Python entry point guard, ensuring the app runs only when executed directly, not when imported as a module.
  • app.run(debug=True): Starts the built-in development server with automatic code reloading and an interactive browser debugger.
[Client Browser] ──(HTTP GET /)──> [WSGI Server / Werkzeug] │ [URL Routing Map] │ [home() View Function] │ [Client Browser] <──(HTTP 200 "Hello...")─┘
Exam Memory Trick: Remember I-I-R-R: Import Flask → Instantiate (app = Flask(__name__)) → Route (@app.route()) → Run (app.run()).

HTTP Methods & URL Building with url_for()

from flask import Flask, redirect, url_for

Common Written Exam Mistake: Confusing the function name with the URL path inside url_for(). Always write url_for('function_name', param=val), NOT url_for('/route/url')!

03. Request & Response Objects

Flask provides global context objects (thread-local proxies) to examine client requests and craft precise HTTP responses.

Key Attributes of request

  • request.method: Returns HTTP verb ('GET', 'POST', 'PUT', 'DELETE').
  • request.form: ImmutableMultiDict containing parsed HTML form input data (from POST).
  • request.args: ImmutableMultiDict containing URL query parameters (e.g. ?search=beach&page=2).
  • request.json or request.get_json(): Parsed JSON payload from API requests.
  • request.cookies: Dictionary containing cookies passed by the browser.
  • request.headers: HTTP request headers dictionary (e.g. User-Agent).

Crafting Custom Responses with make_response()

from flask import Flask, make_response, jsonify

app = Flask(__name__)

@app.route('/custom-resp')
def custom_resp():
    resp = make_response("Custom Body Text", 201)
    resp.headers['X-Custom-Header'] = 'ExamGuide'
    resp.set_cookie('exam_tracker', 'completed', max_age=3600)
    return resp

05. Forms, POST & CSRF Security

Form handling is the backbone of web user interaction. Secure Flask applications always distinguish GET (displaying form) from POST (processing submission) and enforce CSRF (Cross-Site Request Forgery) protection.

Complete Form Processing Pattern

from flask import Flask, render_template, request, flash, redirect, url_for

app = Flask(__name__)
app.secret_key = 'super_secret_exam_key'

@app.route('/create-trip', methods=['GET', 'POST'])
def create_trip():
    if request.method == 'POST':
        title = request.form.get('title', '').strip()
        budget = request.form.get('budget', '').strip()

        # Input Validation (Essential for full marks in exams)
        if not title:
            flash("Trip title is required!", "danger")
            return render_template('trip_form.html')
        
        try:
            budget_val = float(budget)
            if budget_val < 0:
                raise ValueError()
        except ValueError:
            flash("Budget must be a positive number!", "danger")
            return render_template('trip_form.html')

        # Logic for saving into DB...
        flash(f"Trip '{title}' saved successfully!", "success")
        return redirect(url_for('trip_list'))

    return render_template('trip_form.html')
Post/Redirect/Get (PRG) Pattern: Explain why we use redirect() after successful POST. If the user clicks "Reload", the browser prompts "Confirm form resubmission" causing duplicate database records. Redirecting to a GET route completely prevents this bug!

06. Client Sessions & Cookies

HTTP is a stateless protocol. Flask sessions store key-value data across subsequent user requests using cryptographically signed cookies.

How Flask Sessions Work

  • Flask stores session data directly in a browser cookie named session.
  • It uses app.secret_key to digitally sign the cookie with HMAC-SHA1/SHA256.
  • Crucial Exam Fact: Client-side cookies are readable (base64 decoded) by the client unless encrypted, but they are tamper-proof (the server rejects any cookie modified without the secret key).
from flask import Flask, session, redirect, url_for

app = Flask(__name__)
app.secret_key = 'my-exam-signing-key'

@app.route('/set-session/<username>')
def login_sim(username):
    session['logged_in_user'] = username
    return f"Session established for {username}"

@app.route('/get-session')
def dashboard():
    user = session.get('logged_in_user')
    if not user:
        return redirect(url_for('login'))
    return f"Welcome back, {user}!"

@app.route('/logout')
def logout():
    session.pop('logged_in_user', None)  # Safe removal
    # or session.clear() to remove all keys
    return "Logged out!"

07. User Authentication & Password Hashing

Passwords must NEVER be stored in plain text. Flask applications use Werkzeug Security to salt and hash credentials.

Werkzeug Security Functions

from werkzeug.security import generate_password_hash, check_password_hash

# During Registration:
plain_password = "user_secret_123"
hashed_password = generate_password_hash(plain_password, method='pbkdf2:sha256')
# Store hashed_password into MySQL / SQLite database

# During Login:
entered_password = "user_secret_123"
is_valid = check_password_hash(hashed_password, entered_password) # Returns True/False

# 1. Fetch user by username
user = db.query("SELECT * FROM users WHERE username = %s", (entered_user,))

08. Database Operations with Raw SQL (mysql.connector)

Direct relational database connectivity using Python cursors and parameterized queries to prevent SQL Injection.

The 5 Steps of Database Execution

  1. Connect: conn = mysql.connector.connect(...)
  2. Cursor: cursor = conn.cursor(dictionary=True)
  3. Execute: cursor.execute(sql_query, tuple_params)
  4. Commit: conn.commit() (Mandatory for INSERT, UPDATE, DELETE)
  5. Close: cursor.close() and conn.close()
import mysql.connector

def get_db_connection():
    return mysql.connector.connect(
        host="localhost",
        user="root",
        password="premsai444@123",
        database="trip_planner_db"
    )

def fetch_trips_by_user(user_id):
    conn = get_db_connection()
    cursor = conn.cursor(dictionary=True)
    try:
        # Parameterized query with %s prevents SQL injection
        cursor.execute("SELECT * FROM trips WHERE user_id = %s", (user_id,))
        trips = cursor.fetchall()
        return trips
    finally:
        cursor.close()
        conn.close()

09. Modern SQLAlchemy 2.0 & Flask-SQLAlchemy 3.x

SQLAlchemy Object Relational Mapper (ORM) represents database tables as Python classes and table rows as Python class instances.

Modern Declarative Model Syntax (SQLAlchemy 2.0)

from flask import Flask
from flask_sqlalchemy import SQLAlchemy
from sqlalchemy.orm import DeclarativeBase, Mapped, mapped_column
from sqlalchemy import String, Integer, Float, ForeignKey
from datetime import datetime

class Base(DeclarativeBase):
    pass

db = SQLAlchemy(model_class=Base)
app = Flask(__name__)
app.config['SQLALCHEMY_DATABASE_URI'] = 'sqlite:///exam.db'
db.init_app(app)

class User(db.Model):
    __tablename__ = 'users'
    id: Mapped[int] = mapped_column(Integer, primary_key=True)
    username: Mapped[str] = mapped_column(String(80), unique=True, nullable=False)
    created_at: Mapped[datetime] = mapped_column(default=datetime.utcnow)

class Trip(db.Model):
    __tablename__ = 'trips'
    id: Mapped[int] = mapped_column(Integer, primary_key=True)
    title: Mapped[str] = mapped_column(String(120), nullable=False)
    budget: Mapped[float] = mapped_column(Float, default=0.0)
    user_id: Mapped[int] = mapped_column(ForeignKey('users.id'), nullable=False)

Session Operations in SQLAlchemy 2.0

  • Create: db.session.add(new_obj); db.session.commit()
  • Read: item = db.session.get(Trip, 1) or items = db.session.execute(db.select(Trip).where(Trip.budget > 500)).scalars().all()
  • Update: item.budget = 750.0; db.session.commit()
  • Delete: db.session.delete(item); db.session.commit()

10. Complete Single-File CRUD Architecture

Exam questions regularly ask to write a complete CRUD module in a single app.py script.

from flask import Flask, request, jsonify

app = Flask(__name__)
# In-memory storage dictionary simulating database
DATA_STORE = {}
COUNTER = 1

# 1. CREATE
@app.route('/items', methods=['POST'])
def create_item():
    global COUNTER
    payload = request.get_json()
    item_id = COUNTER
    DATA_STORE[item_id] = payload
    COUNTER += 1
    return jsonify({"id": item_id, "data": payload}), 201

# 2. READ ALL
@app.route('/items', methods=['GET'])
def get_all_items():
    return jsonify(DATA_STORE), 200

# 3. READ ONE
@app.route('/items/<int:item_id>', methods=['GET'])
def get_single_item(item_id):
    item = DATA_STORE.get(item_id)
    if not item:
        return jsonify({"error": "Item not found"}), 404
    return jsonify({"id": item_id, "data": item}), 200

# 4. UPDATE
@app.route('/items/<int:item_id>', methods=['PUT'])
def update_item(item_id):
    if item_id not in DATA_STORE:
        return jsonify({"error": "Item not found"}), 404
    DATA_STORE[item_id] = request.get_json()
    return jsonify({"message": "Updated successfully"}), 200

# 5. DELETE
@app.route('/items/<int:item_id>', methods=['DELETE'])
def delete_item(item_id):
    if item_id not in DATA_STORE:
        return jsonify({"error": "Item not found"}), 404
    del DATA_STORE[item_id]
    return jsonify({"message": "Deleted successfully"}), 200

12. Error Handling & Custom Pages

Flask provides @app.errorhandler to catch HTTP status errors and Python exceptions, returning custom user-friendly HTML pages instead of raw tracebacks.

from flask import Flask, render_template

app = Flask(__name__)

@app.errorhandler(404)
def page_not_found(error):
    # Notice: returning the status code 404 as the second tuple element is required!
    return render_template('404.html'), 404

@app.errorhandler(500)
def internal_server_error(error):
    return render_template('500.html'), 500
Exam Rule: When writing custom error handlers in a paper exam, never forget to append the status code at the end of the return statement (e.g., return render_template('404.html'), 404). If omitted, Flask will default to sending 200 OK!

13. Custom Decorators & Hooks

Decorators wrap view functions to enforce authorization, session validation, or logging without duplicating code across routes.

Creating a Custom @login_required Decorator

from functools import wraps
from flask import session, redirect, url_for, flash

def login_required(f):
    @wraps(f)
    def decorated_function(*args, **kwargs):
        if 'user_id' not in session:
            flash("Please log in first to access this page.", "warning")
            return redirect(url_for('login'))
        return f(*args, **kwargs)
    return decorated_function

# Using the decorator
@app.route('/my-trips')
@login_required
def my_trips():
    return "User Protected Trips List"
Why @wraps(f) is mandatory: Flask uses the function name (__name__) to register URL endpoints. Without @wraps(f), all decorated functions will take the name 'decorated_function', causing an AssertionError: View function mapping is overwriting an existing endpoint function!

14. Context Globals (g, current_app)

Flask provides application and request context globals that exist for the lifetime of a single request.

  • flask.g: A namespace object for storing data during a request (e.g. database connections, authenticated user object). It is reset between requests.
  • flask.current_app: Points to the active application instance handling the request (useful in blueprints and helper functions).
from flask import g
import sqlite3

def get_db():
    if 'db' not in g:
        g.db = sqlite3.connect('database.db')
        g.db.row_factory = sqlite3.Row
    return g.db

@app.teardown_appcontext
def close_db(exception):
    db = g.pop('db', None)
    if db is not None:
        db.close()

16. Predict the Output (Written Exam Scenarios)

Scenario 1: Default String Converter and Trailing Slashes 
@app.route('/items/')
def items_list():
    return "List of Items"

# Question: What happens when the user visits http://localhost:5000/items (without trailing slash)?

Answer: Flask automatically returns an HTTP 308 Permanent Redirect pointing the browser to /items/, which then responds with "List of Items" (Status 200). Flask standardizes canonical URLs with trailing slashes.

Scenario 2: Variable Type Conversion 
@app.route('/calculate/<num>')
def calc(num):
    return num * 2

# Question: What is returned if the user requests /calculate/5 ?

Answer: It returns "55"! Because no converter type was specified, num defaults to a str. In Python, "5" * 2 concatenates strings rather than performing arithmetic. To perform math, use <int:num>.

Scenario 3: Missing Secret Key Exception 
app = Flask(__name__)
# Notice app.secret_key is NOT defined

@app.route('/login')
def test():
    session['user'] = 'Prem'
    return "Logged in"

Answer: The app crashes with a RuntimeError: The session is unavailable because no secret key was set. Set the secret_key on the application to something unique and secret.

@app.route('/submit')

    if request.method == 'POST':
        return "Received"

# FIX:
@app.route('/submit', methods=['GET', 'POST'])

cursor.execute("INSERT INTO users (username) VALUES (%s)", (username,))
# FIX:
cursor.execute("INSERT INTO users (username) VALUES (%s)", (username,))
conn.commit()  # Without commit(), transaction is rolled back on connection close!

# BUGGY:
@app.route('/user')
def profile(): ...

@app.route('/admin')
def profile(): ... # Name clash!

# FIX: Each view function name must be unique within an application.

18. 30 Exam Questions (2 Marks Each)

  1. What is WSGI? Web Server Gateway Interface; the Python standard (PEP 3333) describing how a web server communicates with web application frameworks.
  2. What is the purpose of __name__ in Flask(__name__)? It allows Flask to locate the root directory of the application to find templates, static, and resource files.
  3. What is the default port of a Flask development server? Port 5000.
  4. What does debug=True do in Flask? Enables automatic code reloading upon changes and displays an interactive debugger on unhandled exceptions in the browser.
  5. Distinguish between request.args and request.form. request.args retrieves URL query parameters from GET requests; request.form parses form payload from POST requests.
  6. Why should app.secret_key be kept confidential? It cryptographically signs session cookies; exposing it allows attackers to forge cookies and impersonate any user.
  7. What does render_template() do? Parses a Jinja2 template file located in the templates/ folder, populates variable placeholders, and returns an HTML string.
  8. What is the default HTTP method for any Flask route? GET.
  9. How do you return JSON from a Flask route? By importing and calling jsonify(data_dict) from flask.
  10. Explain the url_for() function. Dynamically generates the absolute URL for a specific view function by its name, preventing brittle hardcoded URLs.
  11. What is Jinja2 Template Inheritance? A pattern where child templates extend a master base template using {% extends "base.html" %} and override defined {% block %} regions.
  12. What does session.clear() do? Removes all key-value entries stored in the client's current session cookie.
  13. Why must database transactions be committed? Without conn.commit() or db.session.commit(), changes are staged in memory and never written permanently to disk.
  14. How do you redirect a user in Flask? Use return redirect(url_for('destination_function')).
  15. What HTTP status code is sent on redirect() by default? HTTP 302 Found (Temporary Redirect).
  16. What is the function of flash() messages? Displays one-time feedback messages to users that automatically disappear after being rendered in the next request.
  17. What is SQL Injection? A vulnerability where malicious SQL commands are executed because raw untrusted input was directly concatenated into queries.
  18. How does parameterization stop SQL injection? Input is treated strictly as literal data rather than executable SQL syntax (e.g., using %s placeholders).
  19. What is an ORM? Object-Relational Mapping; a technique translating database tables into Python classes and records into Python objects.
  20. What is the role of mapped_column() in SQLAlchemy 2.0? Explicitly configures table column properties (type, primary key, nullable) while maintaining Python type hints.
  21. What does get_json() do? Parses the incoming request body as JSON, returning a Python dictionary or list.
  22. Explain HTTP 404 vs 405. 404 Not Found means the requested URL doesn't exist; 405 Method Not Allowed means the URL exists but doesn't permit the HTTP method (e.g., POST to a GET-only route).
  23. What is the g object in Flask? A thread-local global namespace for sharing data (like a database connection) across functions within a single request.
  24. What is the difference between abort(404) and render_template('404.html')? abort(404) raises an HTTPException immediately halting execution; render_template simply produces the HTML text.
  25. How do you handle file uploads in Flask? Access the file via request.files['file_key'] and save using file.save(path).
  26. What is CSRF? Cross-Site Request Forgery; an attack forcing a logged-in user to execute unwanted actions on a web application where they are authenticated.
  27. How does a CSRF token protect forms? By generating a unique, secret cryptographic token stored in the session and validating that the submitted form includes that matching token.
  28. What is the default hashing algorithm used by Werkzeug? pbkdf2:sha256 with salt.
  29. What is the purpose of @wraps(f) in custom decorators? Preserves the original function's name and docstring, preventing endpoint collision in Flask.
  30. What is a Blueprint in Flask? A modular way to organize a Flask application into reusable, self-contained sub-components with their own routes and templates.

19. 20 Exam Questions (5 Marks Each)

1. Explain the request-response lifecycle of a Flask application with a diagram.

1. Request Arrival: Browser sends HTTP request to the web server (WSGI/Werkzeug).
2. Context Setup: Flask pushes Application and Request Contexts, creating proxies for request, session, and g.
3. URL Matching: The URL routing map identifies the matching view function.
4. View Execution: The view function processes input, queries the database, and calls render_template().
5. Response Generation: Return values are converted to a Response object, session cookies are signed, and contexts are popped.
6. Transmission: Response is returned via WSGI to the client browser.

        u = request.form['username']
        p = request.form['password']
        if u not in USERS:
            flash("User does not exist", "danger")
        elif not check_password_hash(USERS[u], p):
            flash("Incorrect password", "danger")
        else:
            session['user'] = u
            return redirect(url_for('dashboard'))
    return '<form method="POST">Username: <input name="username"><br>Password: <input name="password" type="password"><br><button type="submit">Login</button></form>'

@app.route('/dashboard')
@login_required
def dashboard():
    return f"Welcome {session['user']}! <a href='/add'>Add Item</a> | <a href='/logout'>Logout</a>"

@app.route('/logout')
def logout():
    session.clear()
    return redirect(url_for('login'))

if __name__ == '__main__':
    app.run(debug=True)
