03 · Routing

URL Dispatcher & Decorators

Syntax @app.route("/endpoint") def view_name(): return response
🌳 Route Mapping Tree
📌 Golden Rules of Routing
URL Must start with forward slash /
NAME Every view function must have a unique name
RETURN Must return string, template, or response object
🚫 404 Unmatched Route Catch
When requested URL matches no registered pattern, Flask automatically generates an HTTP 404 NOT FOUND response.

04 · Configuration

Debug Mode & Server Environment

Syntax app.run(debug=True)  # Dev   |   app.run(debug=False)  # Production
⚙️ Development vs Production Comparison
Capability debug=True debug=False
Hot Reload on Code Save ACTIVE OFF
Interactive Browser Console ENABLED OFF
Detailed Stacktrace Error VISIBLE HIDDEN
Security Profile ⚠️ HIGH RISK 🔒 SAFE
🛡️ Security & Diagnostics Gauge
⚠️ Never deploy with debug=True — exposes interactive remote shell!

05 · HTTP Protocol

HTTP Methods: GET vs POST

Syntax GET: request.args.get("key")   |   POST: request.form.get("key")
🔍 GET Method (Data in URL)
• Used for retrieving content & searches
• Bookmarkable in browser history (Limit ~2KB)
🔒 POST Method (Data in Body)
• Used for submitting forms, auth & files
• Never exposed in URL bar (No arbitrary size limit)

06 · Dynamic URLs

Dynamic Routes & Type Converters

Syntax @app.route("/student/<converter:param>") def view(param):
🔍 Dynamic URL Dissection
<string>
Default Text
Any text without slash (/student/alice)
<int>
Integers
Positive numbers only (/student/42)
<float>
Decimals
Floating point (/price/19.99)
<path>
Slashed Path
Accepts slashes (/files/docs/notes.pdf)
